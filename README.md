# Gestionnaire de Tâches

Application console permettant de gérer une liste de tâches (TODO list) avec :
- Ajout de tâches
- Affichage de toutes les tâches
- Marquage comme terminée
- Suppression de tâches
- Sauvegarde dans un fichier

## Auteurs

- Teshani FERNANDO : Backend (gestion des tâches)
- Lina Chellala : Frontend (menu et interface)

## Compilation et lancement

make        # Compiler
make run    # Lancer le programme
make clean  # Nettoyer

L'exécutable se trouve dans est ./gestionnaire.exe
